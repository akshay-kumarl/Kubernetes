A few useful facts on top of the structure:

You scaffold this whole layout automatically with helm create mychart.
Templates use Go templates + Sprig functions, so you get conditionals, loops, and helper functions inside YAML (e.g. {{- if .Values.ingress.enabled }}).
helm template renders manifests locally without installing, good for debugging.
helm install/helm upgrade actually applies the rendered manifests to your cluster.
Multiple environments (dev/staging/prod) are usually handled with separate values files like values-dev.yaml, values-prod.yaml, passed via -f.


  
# Lint for structural errors
helm lint .

# Render templates locally to check output
helm template sampleapp .

# Dry-run against a real cluster (catches API/schema issues)
helm install sampleapp . --dry-run --debug
